# Doctor-Tracker

## Description
Doctor Tracker is a secure, high-performance administrative web application engineered for healthcare supervisors to monitor physicians, organize patient rosters, and analyze clinical throughput in real time. Built with Next.js 15, Node.js/Express, and MongoDB, the system emphasizes sub-100ms response times through compound database indexing and single-pipeline data aggregation.
